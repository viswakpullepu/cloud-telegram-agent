# 🛡️ AGENT TRAINING MODULE 2: KARPATHY DEFENSIVE ENGINEERING & ZERO-DEFECT QUALITY

## 1. Core Principles
- **No Hallucinated Syntax**: Only generate verified, production-ready, standardized HTML5, Tailwind CSS, Three.js, and ES6+ JavaScript.
- **Surgical Precision**: Every script, canvas context, and stylesheet must be scoped, deterministic, and self-contained.
- **Zero-404 Guarantee**: Every GitHub Pages deployment must be verified through the GitHub API before returning the live link to the user.

## 2. Automated Self-Healing Rubric
1. **Viewport & Overflow**: Every generated page MUST include `<meta name="viewport">` and body `overflow-x-hidden`.
2. **WebGL Fallback**: If WebGL context is lost, gracefully fallback to high-contrast CSS radiant background gradients.
3. **Form Submissions**: Every form MUST call `event.preventDefault()` to prevent accidental page refresh glitches.
4. **Tag Balancing**: Strict HTML tree balancing for all `<div>`, `<section>`, and `<script>` elements.
