# 📜 AGENT CODEX: STRICT WHAT TO DO & WHAT NOT TO DO (RULES OF EXCELLENCE)

## ✅ PART 1: THE "WHAT TO DO" GOLD STANDARDS (MANDATORY IN EVERY BUILD)

1. **Craft Bespoke, Luxury, Human-Grade Visuals**:
   - Every website MUST look like an Apple Keynote, Linear, Stripe, or Vercel production launch.
   - Use luxury dark themes (Obsidian Void `#020408` with glowing neon accents).
   - Use Magic UI Bento Grids with Border Beam conic lighting and frosted glassmorphic cards (`backdrop-filter: blur(24px)`).

2. **Always Inject Hardware-Accelerated 3D & Lenis Physics**:
   - Every site MUST have a live, interactive Three.js 3D WebGL shader (Torus Knot, Constellation Particles, or Cyber Globe).
   - Mouse cursor coordinates MUST feed spring-lerp easing into camera and geometry rotation.
   - Always initialize Lenis smooth inertial scrolling for silky 60FPS momentum.

3. **Always Build Fully Functional Interactive Sandboxes**:
   - Every site MUST have a working interactive Terminal CLI with executable commands (`help`, `scan`, `balayya`, `status`, `clear`).
   - Every lead/contact form MUST have functional JS feedback with `e.preventDefault()`.
   - Every telemetry grid MUST have animated pulsing indicators and live counters.

4. **Always Enforce Mobile-First Perfection**:
   - Every build MUST have `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
   - Every body MUST have `class="overflow-x-hidden"` to prevent horizontal glitching on phones.

5. **Always Verify GitHub Pages (Zero-404 Guarantee)**:
   - Poll GitHub Pages API until status is confirmed `"built"` before sending the live URL to the user.

## ❌ PART 2: THE "WHAT NOT TO DO" CARDINAL SINS (STRICTLY PROHIBITED)

1. **❌ NEVER Output "AI Slop" or Generic Cookie-Cutter Templates**:
   - No boring plain white Bootstrap cards with generic grey text.
   - No placeholder "Lorem Ipsum" text — always generate domain-specific, high-impact copy.

2. **❌ NEVER Break Mobile Viewports**:
   - No fixed pixel widths (`width: 1200px`) that cause horizontal cutoff on mobile screens.
   - No tiny unclickable touch targets (minimum 44x44px for buttons).

3. **❌ NEVER Cause Page Reloads on Forms**:
   - Never write a `<form>` without `event.preventDefault()`. A raw form submission that refreshes the page is a bug.

4. **❌ NEVER Drop Frames in WebGL Render Loops**:
   - Never instantiate new Three.js geometries or materials inside `requestAnimationFrame()` (causes catastrophic memory leaks). Always instantiate once outside the loop.

5. **❌ NEVER Annoy the User with 12 Repetitive Questions**:
   - Always accept single-message 5-W briefs, URLs, or screenshots and synthesize immediately.

6. **❌ NEVER Deliver Premature 404 Links**:
   - Never send a link before GitHub Pages has completed propagation worldwide.
